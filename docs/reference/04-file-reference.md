## Swift sources (`leanring-buddy/`)

The folder name retains the misspelling intentionally. **Do not rename.**

### Entry point and chrome

| File | Lines | Role |
|------|-------|------|
| `leanring_buddyApp.swift` | 89 | `@main` `App`. Creates a hidden `Settings` scene (required by SwiftUI). `CompanionAppDelegate` instantiates `MenuBarPanelManager` + `CompanionManager`, registers Login Item, owns the commented-out Sparkle updater. |
| `MenuBarPanelManager.swift` | 243 | `NSStatusItem` (programmatically drawn triangle icon) + borderless `NSPanel` lifecycle. Outside-click monitor. Listens for `.clickyDismissPanel` notification. |
| `CompanionPanelView.swift` | 761 | SwiftUI content of the dropdown panel. Onboarding states, permission Grant buttons, email field, model picker (Sonnet/Opus), DM Farza button, "Watch Onboarding Again" footer, quit. |

### Central state

| File | Lines | Role |
|------|-------|------|
| `CompanionManager.swift` | 1026 | The brain. Owns voice state, conversation history, all UI flags, overlay manager. Hosts the long system prompts. Coordinates the push-to-talk → screenshot → Claude → TTS → pointing pipeline. |

### Voice input pipeline

| File | Lines | Role |
|------|-------|------|
| `GlobalPushToTalkShortcutMonitor.swift` | 132 | Listen-only `CGEventTap` for `ctrl+option`. Publishes `.pressed` / `.released`. Auto-restarts on tap timeout. |
| `BuddyDictationManager.swift` | 866 | Owns `AVAudioEngine`, permission requests with deduplication, audio-level RMS computation for the waveform, transcription session lifecycle. Defines the `BuddyPushToTalkShortcut` enum + transition parser used by the CGEvent tap. |
| `BuddyTranscriptionProvider.swift` | 100 | Protocols (`BuddyTranscriptionProvider`, `BuddyStreamingTranscriptionSession`) and a factory that picks AssemblyAI / OpenAI / Apple Speech from `Info.plist["VoiceTranscriptionProvider"]`. |
| `AssemblyAIStreamingTranscriptionProvider.swift` | 478 | Token-fetch + websocket-streaming provider. Shared `URLSession` across sessions. Turn-based transcript assembly with formatted-turn precedence. |
| `OpenAIAudioTranscriptionProvider.swift` | 317 | Buffer-and-upload provider. Builds multipart WAV upload to `audio/transcriptions`. |
| `AppleSpeechTranscriptionProvider.swift` | 147 | `SFSpeechRecognizer` provider with on-device recognition preferred. |
| `BuddyAudioConversionSupport.swift` | 108 | `BuddyPCM16AudioConverter` (live mic → PCM16 16 kHz mono) + `BuddyWAVFileBuilder` (PCM16 + RIFF header → WAV). |

### AI clients

| File | Lines | Role |
|------|-------|------|
| `ClaudeAPI.swift` | 291 | Streaming SSE client through the Worker `/chat` route. TLS warmup HEAD. Detects PNG vs JPEG and sets `media_type` accordingly. Builds conversation messages with image content blocks. Non-streaming `analyzeImage` variant for validation. |
| `OpenAIAPI.swift` | 142 | OpenAI Chat Completions vision client. Direct to `api.openai.com` (no proxy) — used only when wired in via a configured key. Not on the active hot path. 🪦 SCHEDULED FOR REMOVAL — see `DELETION_PLAN.md`. |
| `ElevenLabsTTSClient.swift` | 81 | POST to Worker `/tts` with `eleven_flash_v2_5`. Plays the returned MP3 via `AVAudioPlayer`. Exposes `isPlaying` and `stopPlayback()`. |

### Screen + overlay

| `ElementLocationDetector.swift` | 335 | Utility for detecting UI element locations inside a screenshot. Not on the current hot path (Claude returns coordinates directly via the `[POINT:...]` tag), but kept for future use. 🪦 SCHEDULED FOR REMOVAL — see `DELETION_PLAN.md`. |

## Xcode project

| File / Dir | Role |
|------|------|
| `leanring-buddy.xcodeproj/project.pbxproj` | Xcode project. |
| `leanring-buddy.xcodeproj/xcshareddata/` | Shared schemes. |

Build using Xcode (`Cmd+R`). **Do not** run `xcodebuild` from the terminal — it invalidates TCC permissions and the app re-prompts for screen recording, accessibility, etc.
